## 基本信息

- 应用名：Torrent115
- 包名：torrent115
- 分类：实用工具 / 下载
- 版本：0.13.6
- 架构：x86 / arm64
- 依赖：Python 3.12（商店依赖 python312）
- 权限：应用数据目录、用户选择的下载目录（可选）

## 简介

磁力搜索 → 115 云下载 → 追剧自动转存。支持多源搜索、115 云下载、Trakt/TMDB 追剧日历、本地下载器与 115 原生上传。

## 功能列表

- 多来源磁力搜索：PanSou、TPB、Nyaa、动漫花园、BTSearch、EZTV、knaben、therarbg、bitmagnet
- TMDB 标题解析与中文翻译
- 115 云下载、任务进度与失败重试
- 追剧/电影自动转存：多预设、AI 排序、来源优先级、离线等待超时
- 本地下载器：qBittorrent / aria2 / Transmission
- 原生 115 上传（秒传 + OSS）
- 移动端适配、深色模式、统一网关
